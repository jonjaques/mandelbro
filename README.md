# mandelbro

Best-of-breed fullscreen Mandelbrot set explorer built with Astro, React, and web workers.

Public repository: [github.com/jonjaques/mandelbro](https://github.com/jonjaques/mandelbro)

## Development

```sh
yarn install
yarn dev
```

## Available Scripts

```sh
yarn dev
yarn build
yarn preview
yarn lint
yarn lint:fix
yarn format
yarn format:check
yarn typecheck
yarn healthcheck
```

## Stack

- Astro 5
- React 19
- Tailwind CSS v4
- TypeScript
- Web Workers for progressive rendering
